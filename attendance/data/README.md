# Data

Cartella per file di lavoro, dataset storici e materiale usato per test e confronto.

## Contenuto attuale

- export e dataset legacy gia' usati nel progetto;
- report Zoom utilizzati per provare l'adapter.

## Regola pratica

- i file gia' tracciati restano come riferimento storico;
- nuovi CSV sensibili non vanno committati automaticamente;
- questa cartella serve a separare i dati dal codice e dalla documentazione.
